# GrowPro Broadcast

## Overview
GrowPro Broadcast is a web application designed to automate the scheduling of WhatsApp messages. Users can input their WhatsApp group ID, message content, and a cron schedule to manage their broadcasts efficiently.

## Project Structure
```
growpro-broadcast
├── public
│   └── index.html
├── src

│   ├── App.js
│   ├── index.js
│   ├── App.css
│   └── index.css
├── package.json
└── README.md
```

## Installation

1. Clone the repository:
   ```
   git clone <repository-url>
   ```

2. Navigate into the project directory:
   ```
   cd growpro-broadcast
   ```

3. Install the dependencies:
   ```
   npm install
   ```

## Usage

1. Start the development server:
   ```
   npm start
   ```

2. Open your browser and go to `http://localhost:3000` to view the application.

## Features

- Schedule WhatsApp messages with a specified cron schedule.
- View a list of scheduled messages.
- User-friendly interface for inputting message details.
